# Python SRE Automation

## About

This repository contains small Python tasks and scripts created using Python, with a focus on concepts that can eventually be applied to Site Reliability Engineering (SRE) and infrastructure automation.

## Task 1: Server List Loop

An exercise using a Python list and a `for` loop to iterate through a list of server names and print a message for each server.

## How to Run

```bash
python3 server_variables.py
```

## Skills Practised

- Python lists
- `for` loops
- String formatting with f-strings
- Basic scripting concepts
