# Python SRE Learning

## About

This repository contains small Python exercises and scripts created while learning Python, with a focus on concepts that can eventually be applied to Site Reliability Engineering (SRE) and infrastructure automation.

## Exercise 1: Server List Loop

A beginner exercise using a Python list and a `for` loop to iterate through a list of server names and print a message for each server.

## How to Run

```bash
python3 server_loop.py
```

## Skills Practised

- Python lists
- `for` loops
- String formatting with f-strings
- Basic scripting concepts
